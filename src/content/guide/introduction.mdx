一个用 Rust 写的轻量级服务器探针。

## 三个部分

| 组件 | 装在哪 | 是什么 |
|---|---|---|
| **hub** | 主控机 | Rust + axum + SQLite 的单个二进制，后台、API 与公开状态页都在里面 |
| **agent** | 每一台被监控的机器 | 静态链接的单文件，读 `/proc`，经 WebSocket 上报 |
| **主题** | hub 里 | 公开状态页的外观，可替换。默认主题已嵌在二进制里 |

```text
agent (Linux VPS) ──WebSocket / JSON-RPC 2.0──▶ hub ──▶ 面板 + 公开状态页
```

连接由 agent 主动发起，被监控的机器因此不必开放任何端口。NAT 后面的机器、只有 IPv6 的机器都能接入。

<Note>
  hub 有 Docker 镜像，agent 没有。被监控的 VPS 通常资源紧张，为一个几 MiB 的静态二进制引入整套容器
  运行时并不划算。
</Note>
